# Homebrew tap for Fingertip

[Fingertip](https://rockykusuma.github.io/Fingertip/) puts a big pointing hand on your Mac screen for presenting: point, draw, add arrows, highlight, spotlight and number your steps.

```bash
brew install --cask rockykusuma/fingertip/fingertip
```

Update with `brew upgrade --cask fingertip`.

Source: [rockykusuma/Fingertip](https://github.com/rockykusuma/Fingertip)
